=== HS More Currency ===
Tags: currency, exchange rate, ajax, woocommerce
Requires at least: 7.4

Converts prices for regular and variable items according to the selected currency rate.

== Description ==

Converts product prices according to the selected currency rate. The plug-in Woocommerce is required!

== Installation ==

ThThis section describes how to install the plugin and configure it to work.

1. Download the entire `hs-more-currency` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin from the Plugins screen in WordPress
3. Use the HS More Currency screen to use the plugin

= What plugin online store supported by your plugin? =

Only Woocommerce.

= How to use HS More Currency? =

Activate the plugin.Choose the currency with which the conversion will be made, save the setting.
Open your product and track the changes. The price will be converted to the selected currency

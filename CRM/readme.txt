# Local CRM System

## About the project

This project is a **local CRM system based on WordPress**, developed as a custom solution for managing users, data and internal business processes.

The project was developed from the early stages, including the creation and customization of the WordPress theme, user authentication and integration with external services.

The project was later **put on hold**, so it is not a finished production system. The repository contains selected files and components that represent the parts of the project I personally worked on.

## My contribution

My work on the project included:

* development and customization of a **custom WordPress theme**;
* development of custom PHP functionality;
* implementation of **Google user authentication (OAuth 2.0)**;
* integration with Google API;
* implementation of user authentication logic and session handling;
* work with REST API requests and JSON data;
* development and modification of WordPress functionality;
* database-related work;
* debugging and troubleshooting;
* testing implemented functionality and fixing errors.

## Google Authentication

One of the implemented features was user authentication using a Google account.

The integration included:

* OAuth 2.0 authorization flow;
* authorization code exchange for an access token;
* retrieving authenticated user's information;
* handling user sessions;
* communication with Google APIs using WordPress HTTP functions.

## Project status

**Status: On hold / Development paused**

The project was stopped during development and was not released as a final production product.

For this reason, the repository should be treated as a **portfolio / development project**, rather than a complete finished CRM system.

## Repository structure

Only the files and components related to my work are included in this repository.

The repository does **not contain the complete WordPress installation**, database dumps, configuration files, credentials or other unnecessary project files.

The purpose of this repository is to demonstrate the code and technical solutions I personally worked on during the development of the CRM system.
